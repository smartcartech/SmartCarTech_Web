ATE Automation - MAX98357A Voice Files
======================================

Put these files in LittleFS under: /voice/

Required format:
- WAV
- PCM (uncompressed)
- 16-bit
- MONO
- Sample rate: 8 kHz to 96 kHz (16 kHz or 24 kHz recommended)

Files and suggested speech:

1. /voice/system_ready.wav
   "ATE Automation System Ready."

2. /voice/auto_with_key.wav
   "Automatic test with key test."

3. /voice/auto_skip_key.wav
   "Automatic test. Key test skipped."

4. /voice/tool_1.wav
   "Testing Tool One."

5. /voice/tool_2.wav
   "Testing Tool Two."

6. /voice/tool_3.wav
   "Testing Tool Three."

7. /voice/wifi_failed.wav
   "WiFi connection failed. Running offline."

8. /voice/ota_failed.wav
   "Firmware update failed."

9. /voice/hardware_error.wav
   "Hardware initialization error."

10. /voice/automation_stopped.wav
    "Automation stopped."

Notes:
- There is NO "Automatic test completed" voice because AUTO/AUTO2 loops Tool 1 -> 2 -> 3 -> 1.
- Button beep is generated by firmware; no beep WAV file is required.
- Button beep applies only to DOWN, OK, PLUS, MINUS, RUN.
- Warning/error events do not have a dedicated warning beep; they use voice only.
- Pressing RUN to stop still produces the normal RUN-button beep, then the "Automation stopped" voice.

MAX98357A wiring used by this firmware:
- BCLK -> ESP32-S3 GPIO15
- LRC/WS -> ESP32-S3 GPIO16
- DIN -> ESP32-S3 GPIO17
- VIN -> 5V
- GND -> GND
- Speaker -> SPK+ and SPK- on MAX98357A


//Convert .mp3 to .wav (PCM 16-bit, Mono, 16 kHz, WAV): Get-ChildItem *.mp3 | ForEach-Object { ffmpeg -i "$($_.FullName)" -ar 16000 -ac 1 -c:a pcm_s16le "$($_.DirectoryName)\$($_.BaseName).wav" }
